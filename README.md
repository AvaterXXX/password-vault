## 能做什么

| 功能 | 说明 |
|------|------|
| **账户管理** | 新增 / 编辑 / 删除账户，分类筛选与搜索 |
| **字段分离** | 标题、账号、密码、二次验证密钥、网站地址、备注各自独立 |
| **二次验证** | 粘贴 TOTP 密钥后自动生成当前验证码，支持一键复制 |
| **常用网站** | 右侧快捷入口，左键打开，右键删除 |
| **国密加密** | SM3 派生主密钥 + SM4-CBC 加密敏感字段 |
| **主密码 / 锁定 PIN** | 启动使用主密码；空闲锁定后可用本次运行的数字 PIN 快速解锁 |

适合记录 ChatGPT 等 AI 账号、邮箱、开发平台等各类登录信息。

## 快速开始

### 环境要求

- Windows / macOS / Linux
- Python 3.10+

### 安装依赖

```bash
git clone https://github.com/AvaterXXX/password-vault.git
cd password-vault
pip install -r requirements.txt
```

### 运行

```bash
python main.py
```

首次启动会要求设置 **主密码**（至少 8 位）。请牢记，丢失后本地密文无法恢复。

首次解锁后可设置 **锁定 PIN**（4–12 位数字）。空闲 15 分钟自动锁定时，主界面会被遮挡，使用 PIN 可快速恢复；PIN 只保存在当前运行的内存中，程序重启仍需主密码。连续输错 5 次会锁定 10 分钟，之后等待时间逐次翻倍，最长 24 小时。

仓库地址：https://github.com/AvaterXXX/password-vault  

**Windows 安装包（Releases）：** https://github.com/AvaterXXX/password-vault/releases  

下载最新版附件 `PasswordVault.exe` 即可直接运行。

## 打包成 exe（Windows）

也可自行从源码打包：

```bash
pip install -r requirements.txt
python build_exe.py
```

默认生成到带时间戳的独立目录（不会覆盖已有发布文件）：

```text
dist/build-YYYYMMDD-HHMMSS/密码保险柜.exe
```

也可以显式指定交付目录；目录中若已有同名 EXE，脚本会拒绝覆盖：

```bash
python build_exe.py --output-dir dist/交付-20260818
```

双击即可使用，无需安装 Python。

## 安全说明

本工具是 **密码管理器**，需要在你输入主密码后解密并回填密码，因此采用 **可逆的国密 SM4 加密**，而不是单向哈希。

| 项目 | 实现 |
|------|------|
| 密钥派生 | 国密 **SM3** 多轮派生（新建库默认 12000 轮） |
| 字段加密 | 国密 **SM4-CBC + SM3-MAC**（GM2，Encrypt-then-MAC；兼容旧 GM1） |
| 保护字段 | 密码、二次验证密钥、备注 |
| 主密码 | 仅存随机盐 + 校验值，**主密码本身不写入磁盘** |
| 锁定 PIN | 仅当前进程有效；不写入数据库，程序退出后必须重新输入主密码 |
| 换密 | 操作前自动备份；元数据与密文同一事务提交 |
| 其它 | 空闲 15 分钟自动锁定、锁定时遮挡并清空表单、PIN 连错后递增等待、复制后定时清空剪贴板、导入/换密互斥 |

**建议：**

1. 使用足够长、复杂的主密码（至少 8 位）  
2. 不要把 `%APPDATA%\AccountVault\` 下的数据库/密钥文件分享给他人  
3. 导出明文（如有）后请妥善保管或及时删除  
4. 换密产生的 `*.before-rekey.*.bak` 备份请妥善保管或在确认无误后删除  

> 说明：没有主密码时，攻击者难以在合理时间内解开密文；安全性很大程度上取决于你的主密码强度。

## 数据存放位置

| 系统 | 路径 |
|------|------|
| Windows | `%APPDATA%\AccountVault\` |
| 其他 | `~/.account_vault/AccountVault/` |

主要文件：

- `vault.db` — 本地数据库（敏感字段已加密）
- 元数据中的盐与校验信息（用于解锁，不可还原主密码）

### 旧版本数据库发现与迁移

启动时不会按 EXE 所在目录或项目目录新建空库。程序按以下固定顺序只读探测：

1. 当前 `%APPDATA%\AccountVault\vault.db`（未设置 `APPDATA` 时即为回退目录）
2. `~/.account_vault/AccountVault/vault.db`（仅当它与当前目录不同）

优先使用已初始化且表结构完整的候选库；如果只有一个候选库则直接继续使用它。发现多个候选库时按上述顺序选择，并在解锁窗口和主界面状态栏提示所选路径。程序不会静默合并、移动或覆盖候选数据库；仓库历史中没有项目目录/EXE 同目录数据库路径，因此这些位置不会被猜测扫描。

旧库仍在原位置直接打开，主密码校验和已有密文保持不变。旧版 Fernet/GM1 密文在成功解锁后才会迁移为当前格式；迁移失败会回滚数据库事务并保留旧密钥文件。

任何需要补表/补列或加密格式迁移的已有数据库，修改前都会在同一目录生成带时间戳的 `*.before-schema.*.bak` 或 `*.before-crypto-migration.*.bak` 备份；修改主密码则生成 `*.before-rekey.*.bak`。确认新版本可正常解锁和读取账户前，请不要删除这些备份。

## 常见问题

**Q：主密码忘了怎么办？**  
A：无法找回。国密设计下没有主密码就不能解密，只能重新建库。

**Q：二次验证填什么？**  
A：填认证器里的 **密钥（Secret）**，不是已经显示的 6 位动态码。支持带空格密钥或 `otpauth://` 链接。

**Q：可以只记录普通网站账号吗？**  
A：可以。分类、网站地址、备注都支持，不限于 AI 账号。

**Q：锁定 PIN 忘了怎么办？**
A：退出程序后重新启动并输入主密码即可；PIN 只在本次运行中有效。自动锁定期间连续输错 5 次会等待 10 分钟，后续等待时间逐次翻倍，最长 24 小时。
